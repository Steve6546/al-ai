```bash

printf '%s\n' "$(git rev-parse HEAD)" > .git/refs/remotes/origin/main
git rev-parse refs/remotes/origin/main     # تحقّق بـrev-parse لا بـcat
```
⇒ `## main...origin/main` بلا `[gone]` ولا «ahead». **والتسلسل الصحيح: ادفع أولاً، ثم اكتب المرجع.**
