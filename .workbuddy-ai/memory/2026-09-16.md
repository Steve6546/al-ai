**والتحقق بـ`git ls-remote origin refs/heads/main` وحده** = `c42e56b…` = `HEAD`. **و`git status -sb`
قال `[gone]` في اللحظة نفسها** — تأكيد جديد للقاعدة: مراجع التتبّع لا تُحفظ هنا.

**والإصلاح:** لا `packed-refs` ولا مرجع سائب ⇒ `branch.main.remote` و`merge` كانا سليمين والمرجع
مفقود فقط. كُتب يدوياً **بعد الدفع**:
```bash
mkdir -p .git/refs/remotes/origin
printf '%s\n' "$(git rev-parse HEAD)" > .git/refs/remotes/origin/main
git rev-parse refs/remotes/origin/main     # تحقّق بـrev-parse لا بـcat
```
⇒ `## main...origin/main` بلا `[gone]` ولا «ahead». **والتسلسل الصحيح: ادفع أولاً، ثم اكتب المرجع.**

**نسخة محمولة:** `git bundle create .workbuddy-ai/backups/al-ai-main-20260916.bundle --all` (1.1MB)
