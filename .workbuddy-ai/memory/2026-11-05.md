## تشغيل «النفق العام» (ngrok)
الطلب: تفعيل «النفق العام — رابط آمن من أي جهاز». الوضع المحفوظ في DB كان `tunnel` أصلاً،
لكن الجولة السابقة بُدئت بـ`AL_AI_REMOTE_ACCESS=off` (افتراضي `dev.ps1`) فلا يوجد ngrok.

**السبب الجذري للفشل الأول (مقيس من `apps/dashboard/.al-tunnel.log`):**
`ERR_NGROK_9009` — الـsandbox يحقن `http_proxy`/`https_proxy` في شجرة العمليات، وخطة ngrok
المجانية ترفض العمل خلف بروكسي HTTP (ميزة مدفوعة). ثلاث محاولات خرجت برمز 1. ملف
`ngrok.yml` نظيف (version + authtoken فقط) فليس هو السبب.

**الحل:** إعادة تشغيل المشرف بلا متغيّرات البروكسي:
`env -u http_proxy -u https_proxy -u HTTP_PROXY -u HTTPS_PROXY -u all_proxy -u ALL_PROXY npm run dev -- -Tunnel`
كمهمة خلفية مُدارة. لا تعديل على الكود ولا على `.env`.

**التحقق:** `dev:status` = DB/لوحة/بوت up + tunnel up (ngrok pid 20176) ·
`ngrok` local API 4040 = `public_url` ثابت · سجل اللوحة `ngrok tunnel is up` ·
`/api/network` بجلسة مالك = `mode:tunnel, tunnelStatus:running, tunnelStable:true, tunnelError:null` ·
الرابط العام `/` و`/api/health` كلاهما **200** (عبر البروكسي ومباشرة، مع
`ngrok-skip-browser-warning`) · البوت `connected as ddas#9766` · لا أخطاء في سجلات الخدمتين.

**⚠️ ما لم يُتحقق:** `tunnelCallbackVerified:false` — لم يكتمل تسجيل دخول عبر أصل النفق،
فلا دليل على أن `https://<domain>/auth/discord/callback` مسجَّل في بوابة Discord. يحتاج
تسجيل دخول حقيقي أو إضافة الـredirect من البوابة. وخطة ngrok المجانية تعرض صفحة تحذير
مرة واحدة للمتصفح.
